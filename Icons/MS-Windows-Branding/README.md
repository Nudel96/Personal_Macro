# MS Windows Branding Package

Aggressive MS monogram branding package for a Windows desktop tool.

## Recommended defaults

- Executable and taskbar: `02-app-icons/app-icon.ico`
- Large in-app logo: `01-master/MS-logo-transparent.png`
- Vector workflows: `01-master/MS-logo-master.svg`
- System tray: choose the white or black 16–24 px variant from `03-tray`
- MSIX/Appx packaging: files in `04-msix`
- Installer: files in `05-installer`

## Visual system

- Near black: `#08090B`
- Silver/ice white: `#F4F6F8`
- Signal red: `#E1062C`

The full metallic source is preserved as `MS-logo-original.png`. Small assets use
a flat, higher-contrast reduction so the MS silhouette remains legible at Windows
taskbar and tray sizes. The SVG is an automatically traced, flat vector master.
